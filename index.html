Koneksi Database Firebase (Cloud Firestore)

Hubungkan aplikasi ke Firebase agar semua guru bisa input nilai secara bersamaan (real-time).

Mode Lokal

Data akan disimpan di Firestore pada koleksi raport_tpq dengan ID dokumen di atas.

Panduan Singkat Setup Firebase (Cloud Firestore):

1. Buka console.firebase.google.com → Buat Project → Tambahkan Web App (ikon </>) untuk mendapatkan apiKey & projectId (bisa salin seluruh snippet firebaseConfig ke kotak tempel cepat di atas).

2. Aktifkan menu Build → Firestore Database → Create Database (pilih lokasi Jakarta asia-southeast2 atau Singapore asia-southeast1, lalu pilih Start in test mode).

3. Di tab Rules Firestore, pastikan aturan mengizinkan baca & tulis:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

4. Klik "Simpan & Hubungkan". Setelah terhubung, klik "Upload Data Lokal" agar data master santri & nilai tersinkron ke cloud.

Backup & Restore Database

Simpan seluruh data (Siswa, Nilai, Guru) ke file untuk cadangan, atau pulihkan dari cadangan sebelumnya.

Backup Data (Ekspor)

Unduh seluruh database saat ini ke dalam 1 file JSON sebagai cadangan aman Anda.

Restore Data (Impor)

Kembalikan data dari file Backup JSON. Peringatan: Data saat ini akan tertimpa!

Kosongkan Database (Hard Reset)

Hapus SEMUA data secara permanen (cocok untuk ganti tahun ajaran baru). Pastikan Anda sudah mem-backup data terlebih dahulu.
